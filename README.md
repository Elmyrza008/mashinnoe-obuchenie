# Машинное обучение

Домашняя работа по дисциплине «Машинное обучение».

ФИО: ____________________

## Состав проекта

- `data/` — учебные датасеты для практических работ.
- `notebooks/` — notebook-файлы для практических работ №1–7.
- `reports/` — готовые текстовые отчеты и выводы.
- `plots/` — сохраненные графики.
- `requirements.txt` — зависимости проекта.

## Практические работы

1. Настройка окружения и первый notebook.
2. Разведочный анализ данных.
3. Пайплайн предобработки.
4. Линейная регрессия.
5. Логистическая регрессия и метрики классификации.
6. Классификация текстов.
7. Случайный лес.

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter notebook
```
