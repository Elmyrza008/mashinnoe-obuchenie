## Как добавить материал

1. Создайте файл `lecture_XX_<короткое-название>.md` по [шаблону](TEMPLATE.md).
2. Положите выданные слайды или дополнительные файлы в `lectures/materials/` и укажите их в конспекте и реестре. Создавайте `materials/` только при появлении файлов.
3. Запишите источник, дату занятия, ключевые понятия, формулы/алгоритмы, примеры, вопросы и связь с практикой.
4. Не загружайте закрытые материалы, персональные данные и файлы, на распространение которых нет разрешения. Для больших файлов используйте ссылку на разрешённое хранилище.
