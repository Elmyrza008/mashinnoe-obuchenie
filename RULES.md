# Правила выполнения практических работ

1. Работайте в отдельном Jupyter Notebook и выполняйте ячейки сверху вниз.
2. Перед обучением изучите схему и типы данных; фиксируйте random_state для воспроизводимости.
3. Делите выборку до подгонки преобразований. Все обучаемые преобразования (импутация, масштабирование, отбор признаков, PCA) размещайте в `Pipeline`, чтобы они обучались только на соответствующей обучающей части каждого CV-фолда.
4. Тестовую выборку используйте для итоговой оценки после выбора модели и параметров. Не выбирайте гиперпараметры и пороги по тесту.
5. Выбирайте метрику исходя из задачи; при дисбалансе показывайте метрики классов и матрицу ошибок, а не только accuracy.
6. Для кластеризации обязательно описывайте группы через признаки и ограничения метода; один silhouette не является содержательным выводом.
7. Сохраняйте выводы, таблицы и графики; не заявляйте причинность по важности признаков.
8. В отчёте укажите цель, данные, методику, параметры, результаты, выводы и ограничения. Соблюдайте структуру файла из соответствующего README задания.
9. Не публикуйте персональные данные, секреты, токены, пароли или закрытые наборы данных.
10. Для медицинских, финансовых и иных значимых решений результаты учебных наборов не являются профессиональной рекомендацией.
