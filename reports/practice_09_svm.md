# Практическая работа №9. Метод опорных векторов

Выполнен уровень B в `notebooks/practice_09_svm.ipynb` на датасете диагностики рака молочной железы. Использованы стратифицированное разбиение train/test (80/20, `random_state=42`) и 5-fold StratifiedKFold. Стандартизация находится внутри Pipeline, чтобы исключить утечку при CV. Подбор проведён по macro F1 только на train; test оставлен для финальной оценки.

Для проверенной сетки лучшая модель — SVC с RBF-ядром, `C=10`, `gamma=0.01`. Средний CV macro F1: **0,9739**; финальный test macro F1: **0,9812**. Ноутбук строит тепловую карту `C`/`gamma`, график train/CV по `C` и сводную таблицу сравнения baseline, линейного SVM и настроенного SVM.

Стандартизация обязательна для SVM, поскольку его граница и ядровые расстояния зависят от масштаба признаков. Результат относится к одному фиксированному разбиению и не является оценкой стабильности на всех возможных выборках. Сравнение с ПР-7/8 требует тех же данных, разбиения и метрики.
